## What you did today

<span class="persona-badge persona-badge--ba">BA</span> You made a vague requirement measurable and turned it into test cases, including the over-65 case that caught the defect.

<span class="persona-badge persona-badge--uat">UAT</span> You ran the same test case yourself, with Delegate and with a robot, and saw all three stop at the same UiBank defect.

<span class="persona-badge persona-badge--qa">QA</span> You built and ran a regression set with Autopilot chat, read the results without being fooled by 100% coverage, and called **NO-GO** on a broken acceptance criterion, not on a success rate.

## Which helper for which job

| Helper | Use it to | Good to know |
|---|---|---|
| **Autopilot buttons** in Test Manager | Evaluate a requirement, generate test cases, create the Execution Insights report | Dedicated buttons don't use your AI usage pool |
| **Autopilot chat** in Test Manager | Ask about your project, label test cases, build test sets, triage failures, draw charts, write a go/no-go summary | In Edit mode it asks before each action. With the standard tools it can't start runs or create Execution Insights. Each prompt uses your AI usage pool |
| **Delegate** on your desktop | Run a manual test case on UiBank, reproduce a defect with screenshots, write a PDF report | Works with your mouse and keyboard. Each task uses your AI usage pool |
| **Robots** | Run a test case autonomously (Preview), run the automated regression set on **Cloud - Serverless Testing** | Started from Test Manager, no code. Runs use your organization's robot capacity |
| **Studio Web** | Turn a test case into an automated test (your trainer showed it) | You reused the trainer's tests with **Select Automation** |

Costs and limits are explained in <a href="https://docs.uipath.com/autopilot/other/latest/user-guide/autopilot-usage-pool-for-testing" target="_blank">Autopilot usage pool for testing</a>.

!!! quote "Remember"
    The helpers do the legwork. You decide what to test, which failures matter, and whether to ship.
