    Troubleshooting¶

    Find your symptom in one of the four tables: Delegate, Autopilot chat, runs, or reports. If nothing fits, ask your trainer.

    Delegate¶

    Symptom Likely cause / fix
    Delegate isn't in UiPath Assistant Your UiPath Assistant is too old, or Delegate wasn't selected during the install. Install it again as in Prerequisites and check the version starts with v26. On a Mac, Delegate for macOS (Preview) needs Apple silicon and macOS 14 or later. Still no Delegate? Every Delegate part of the workshop has a browser path – or pair up with a neighbour.
    Delegate asks for approval on every step The approval mode is Cautious. Switch it to Adaptive in the mode selector next to the chatbox (or Settings → Security). Delegate still asks before it changes data or starts a run – that's expected. Can't change the mode? Your admin may have locked it: ask your trainer. See Tasks and prompts troubleshooting.
    Delegate can't find your project Delegate is connected to the wrong tenant, or it's looking for the wrong project. Ask Delegate "List the tenant I am connected to." If the tenant is wrong, switch it in UiPath Assistant as described in Set up Delegate, then run the sign-in command from Connect Delegate to Test Manager again. Always name your project by its prefix in the prompt.
    401 Unauthorized, Authentication failed, or Delegate says you're not signed in to Test Manager Delegate's Test Manager sign-in has expired. Open a new PowerShell window (Windows) or Terminal window (macOS), paste the uip login … command from Connect Delegate to Test Manager again, and sign in with your workshop account in the browser window that opens. Then repeat your prompt. See Delegate for Testing setup FAQ.
    Delegate says it can't find uip, or uip is "not recognized" / "command not found" Delegate was already open when the sign-in tool was installed, so it doesn't see it yet. Quit UiPath Assistant completely and open it again. Still missing? In a new PowerShell or Terminal window, type uip --version. If no version appears, run the install command from Connect Delegate to Test Manager again.
    Delegate pauses or stops with a usage message Your monthly AI and Agentic usage pool is spent. Delegate doesn't fall back to paid usage – it pauses until an admin grants a top-up or the month resets. Tell your trainer, and use the browser path in the meantime. Meanwhile, pair with a neighbour or follow the trainer's screen. See Autopilot usage pool for testing.

    Autopilot chat¶

    Symptom Likely cause / fix
    No Autopilot icon The icon appears only inside a project. Open your project first – the icon is in the top bar. Still missing inside a project? Your user licence doesn't include chat: it needs an App Tester or App Test Developer licence. Ask your trainer. See User licenses.
    Chat asks you to Accept or Reject every tool, even for reading That's how Edit mode works: one approval per Test Manager tool, reads included. An overview prompt takes about five clicks. Read the tool name on each card and accept. Stay in Edit mode for the workshop.
    Chat's counts don't match Execution Chat and its search can miscount, or read a different execution. Check the numbers in Execution. Ask again and name the execution, for example "the latest execution of Release 2.4 - Loan regression".
    Chat says it can't do something, or only explains how There's no tool for it. With the standard Test Manager tools, chat can't start, schedule or stop a run, or create Execution Insights. Use the buttons: Execute → Automated or Create Schedule on the test set, and Generate Report in Execution. If chat can't add labels or create a test set either, open ⚙ Chat settings → MCP Servers and check that Test Manager MCP server is listed under From your organization. If it isn't, tell your trainer.
    A chart prompt returns a list, or says Failed to apply Ask for the chart in so many words: "Show a chart of failed test cases grouped by requirement." Some groupings, such as by label, don't chart: ask for a table instead.
    A "how do I" answer doesn't match what you see Chat can be wrong about how Test Manager works – the panel says so at the bottom. For example, it may say you can't run a single test case on its own, but Execute Manually is in the test case's ⋮ menu. Check against this guide or the docs.
    A turn is very slow, or ends with an error Prompts that read several things take 1–2 minutes, plus your approvals. If a turn fails, click New chat and send a shorter prompt. Don't resend the same prompt again and again: every turn uses your usage pool.
    Chat pauses or stops with a usage message Your monthly usage pool is spent, and chat doesn't fall back to paid usage. Tell your trainer. The Autopilot buttons (Evaluate quality, Generate Report, and so on) don't use the pool and keep working. Meanwhile, pair with a neighbour or follow the trainer's screen.
    Add to Requirement or a suggestion's status drop-down opens "You do not have the necessary rights to access this application." with Click here to logout Suggestions made by the + Evaluate quality button can't be applied with workshop rights. Don't click Click here to logout: press the browser Back button. Run the evaluation in Autopilot chat instead and select Review – in that list Add to Requirement works. See 2. Evaluate the Requirement
    You accepted a change you didn't want Undo it by hand in Test Manager, or ask chat in Edit mode to undo it (for example, "Remove the label release-2.4 from …") and check the tool card before you accept.

    Runs¶

    Symptom Likely cause / fix
    Your Run autonomously (Preview) run stays Pending Usually normal: all learners share one robot, which runs one job at a time (about 6 minutes each), and the first run of the day can wait up to about 10 minutes while the robot's machine starts. Still Pending after lunch? Check the Runtime type you picked: use the one your trainer gave you. Cloud - Serverless Testing is in the list but isn't supported for Run autonomously – start a new run with the right runtime. If the runtime is right, the folder may have no robot account that can run unattended jobs: tell your trainer.
    The Run autonomously panel stops with an error before Autonomous test execution job triggered. Usually a missing permission in the workshop folder (uploading the test package or creating the process). Don't click Run again. Tell your trainer, who adds the permission (see Trainer Setup). Meanwhile, carry on with Execute Manually and Delegate, and use the trainer's completed run in step 5.
    You can't continue in the Run autonomously panel (Next or Run is disabled) The Url field on the first screen is empty. It's pre-filled only when the test case's Manual Steps → URL field is filled in (the Url you type is saved there). Enter https://uibank.uipath.com, the UiBank home page, as in 4. Run the Test Three Ways, click Next, then Run.
    Your Run autonomously run ends after about a minute, step 1 Failed, the other steps None The run didn't reach the age decision – not a UiBank defect. Open the test case's Manual Steps → URL field: it must be exactly https://uibank.uipath.com. Typing into a pre-filled Url adds to the old address (for example …/loans/applyhttps://…). Clear the field and type it again. If step 1's Behaviour verification says "Verification could not be completed (HttpRequestException)", it was a service error. Ask your trainer before you start another run – each run costs App Test Platform Units – and use the trainer's completed run in step 5.
    Project Settings shows "Folder does not exist.", and Default Folder is blank after a reload Your account can't view the workshop folder's details, although your choice may have saved. Tell your trainer, who checks your folder permissions (see Trainer Setup).
    HTTP 400: Please assign folder to project level before executing testcases. Your project has no Default Folder. Set it to ATB - Agentic Testing Workshop as in 1. Import Your Project and Meet Autopilot Chat.
    The Execute Manually window didn't open Your browser blocked the pop-up. Allow pop-ups for Test Manager, then open the test case and select Execute ▾ → Manually again. A run started without a test set can't be re-executed, so a new manual run simply creates a new run.
    Your manual run stays Running in Execution The assistant window was closed without Done. Start a new manual run and finish it with Done on the postcondition. Leave the old run as it is.
    Select Automation shows an entry called TestCase It's an empty default file in the trainer's package. Ignore it, and pick the test with the same name as your test case.
    You can't see the trainer's package in Select Automation Check that Package Source is Tenant Package Feed. If the list is still empty, tell your trainer.
    Select Automation says No results when you search for UiBank.BusinessTests The search box matches test case names only. Type the test case name, for example Over-65, or use the Package filter: tick UiBank.BusinessTests and select Apply.
    A test case in the regression set is skipped, with no result It isn't linked to the trainer's automation. Link it as in 6. Automate with Studio Web and check that Package Name is filled in on the test case's Automation tab.
    Execute → Automated isn't available on the test set The set has no automated test case. Link the test cases first (step 6), then check the set in 7. Build and Run the Regression Set.
    The regression run waits a long time, or runs on the shared robot Configure Automation was saved with Cloud - VM Testing (or the Runtime type was left empty). On the test set, open Configure Automation, set Runtime type to Cloud - Serverless Testing, click Save, and run the set again.
    More than one test case failed, or a failure has no UiBank message Probably a robot error, not a UiBank defect: Test Manager records both as Failed (Orchestrator shows the job as Faulted either way). Open the failed test case log. A real UiBank failure has an assertion that quotes UiBank's page, such as "Congrats! You've been approved…". A robot error has no assertion and an error such as "Failed to start browser". Tell your trainer and run the set again. Don't triage a robot error as a UiBank defect.
    UiBank approves the over-65 applicant ("Congrats! You've been approved…") That's the defect the workshop is built on, and it's expected. In a manual run, mark the step Failed and keep going. Delegate and the robots record the failure for you. It gives the NO-GO in step 9.
    UiBank rejects the over-65 applicant UiBank has fixed the defect, so your over-65 test case passes. Tell your trainer – they switch the class to a spare failing test and explain what changes in steps 7–9.
    "We weren't able to locate a matching loan ID" The loan ID doesn't exist in UiBank. In UiBank, go to Products → Loans → Apply For A Loan, submit an application, and use the new loan ID it shows.

    Report¶

    Symptom Likely cause / fix
    The Execution Insights report is empty or misses your runs The imported results are three years old, so the "last 7/15/30 days" options see only today's runs. In Execution, use Generate Report → From selection (tick the results of your regression execution) or From last day.
    You can't find the Execution Insights report It takes about a minute. Open the Reports tab in Execution, then click the Download icon: you get a .docx file with a long generated name. Rename it.
    The Dashboard doesn't show the imported results, or you can't pick a date range The Dashboard shows Daily or Weekly results for recent weeks only, with no custom date range. Imported results never appear; today's runs do.
    You can't find the execution PDF Open the execution in Execution, click the download icon, and select Download Pdf.
    You can't find Delegate's report Delegate shows the path when it finishes. If it saved the file somewhere hard to find, ask Delegate "Create a PDF of the report and copy it to my Downloads folder."
    The report numbers don't match Test Manager Make sure you're comparing the same execution: ask Delegate or chat which execution it used. A rerun of the failures updates that execution, so its numbers change after a rerun.

    Still stuck?

    Ask your trainer, or ask Autopilot chat or Delegate, for example: "Why did that last step fail, and how do I fix it?" Check the answer before you act on it.
